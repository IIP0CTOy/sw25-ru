# Foundry VTT 用 ソード・ワールド2.5 システム（sw25-ru）

[English](README.md) · [Русский](README-RU.md)

Foundry Virtual Tabletop（v14）で『ソード・ワールド2.5』を遊ぶための、非公式のファンメイドのゲームシステムです。キャラクター・魔物シート、ダイスロール、戦闘、魔法、効果の処理を自動化します。インターフェースは日本語・英語・ロシア語・韓国語に対応しています。

> **ベータ版です。** 遊べる状態ですが、テストしたのは1グループだけです。不具合は [Issues](https://github.com/IIP0CTOy/sw25-ru/issues) へお願いします（日本語で大丈夫です）。

Jean.N さんと協力者の皆さんによる [sw25-fvtt](https://github.com/jeannjeann/sw25-fvtt)（MITライセンス）のフォークです。

## 含まれるもの

自動化に最低限必要な用語だけを収録しています。初めてGMがワールドに入ったときに、114件のスターターデータが辞典として作られます。

| 種類 | 件数 | 内容 |
|---|---|---|
| 技能 | 19 | 名前、分類、経験点テーブル（A/B） |
| 判定 | 43 | 名前、使う技能と能力値 |
| 種族特徴 | 22 | 名前、種族、1行の要約（独自の文章） |
| 練技 | 30 | 名前、MP、効果時間、数値の修正、1行の要約（独自の文章） |

名前と数値はルールブック由来、要約は作者が書いたものです。プログラムには、技能・種族・生まれ・約100の能力の名前と、自動化に必要な数値（キャラクター作成時の能力値ダイスなど）も含まれます。

ほかに、このプロジェクトのために作ったサンプルのキャラクターと魔物（ルールブックのものではありません）と、自分でデータを入力する方法のガイドが付いています。

## 含まれないもの・追加方法

武器・防具・アイテム・魔法・戦闘特技・魔物は含まれていません。GMがお手持ちのルールブックから入力します。

- **アイテムビルダー** — 武器、防具、装飾品、道具、魔法、戦闘特技、賦術、呪歌の入力フォーム。プレイヤーも自分のキャラクター用に使えます。
- **魔物ジェネレーター** — 数値を入力するか、自分で入力・コピーしたデータのテキストを貼り付けます。複数部位の魔物にも対応。
- **ゆとシート読み込み** — ゆとシートⅡで作ったキャラクター・魔物をJSONで読み込めます。

## 自動化の内容

- 技能・能力値・装備から命中力、回避力、ダメージ、防護点を計算。
- 判定・攻撃・魔法をワンクリックで：コスト、ロール、対象の抵抗、ダメージや効果。
- 戦闘中に自動で切れる時間制の効果、再生や継続ダメージ。
- 技能ごとのリソース：バードの楽素、アルケミストのカード、エンハンサーの練技など。
- 複数部位の魔物、範囲・射線の能力。
- キャラクター作成ウィザード、休息、成長、戦利品、簡単なショップ、セッション終了時の報酬。

## インストール

Foundry VTT → ゲームシステム → システムをインストール → 次のマニフェストURLを貼り付け：

```
https://github.com/IIP0CTOy/sw25-ru/releases/latest/download/system.json
```

ワールド作成時にシステム「Sword World 2.5 Plus」を選んでください。Foundry本体を日本語にするには、日本語化モジュール（例：`lang-ja`）を入れてください。

初回起動時、GMの言語が日本語ならスターター辞典とガイドも日本語で作られます。あとから言語を変えるときは、「辞典」タブの「SW25：スターター辞典」ボタンから選べます。

**元の sw25-fvtt との併用について：** このシステムのIDは `sw25-ru` で、元の `sw25` とは別のシステムです。同じFoundryに両方入れられますが、ワールドはどちらか一方のシステムで作ります。
