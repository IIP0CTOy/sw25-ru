# Sword World 2.5 для Foundry VTT (sw25-ru)

[English](README.md) · [日本語](README-JA.md)

Неофициальная фанатская система, которая автоматизирует игру по Sword World 2.5 в Foundry Virtual Tabletop (v14): листы персонажей и монстров, броски, бой, заклинания и эффекты. Интерфейс на русском, английском, японском и корейском.

> **Бета.** Играть можно, но проверяла одна группа. Об ошибках пишите в [Issues](https://github.com/IIP0CTOy/sw25-ru/issues).

Форк [sw25-fvtt](https://github.com/jeannjeann/sw25-fvtt) (Jean.N и участники, лицензия MIT).

## Что входит

Автоматике нужен минимум игровых терминов. При первом входе мастера в мире создаётся стартовый набор из 114 записей:

| Вид | Записей | Что в каждой |
|---|---|---|
| Классы | 19 | название, тип класса, таблица опыта (A/B) |
| Проверки умений | 43 | название, класс и характеристика |
| Расовые способности | 22 | название, раса, строка-сводка своими словами |
| Техники Усилителя | 30 | название, ОМ, длительность, числовой модификатор, строка-сводка своими словами |

В этих записях названия и числа, которые происходят из книг правил, и короткие сводки, написанные автором сборки. В коде программы также есть названия классов, рас, предысторий и около сотни способностей с числами правил, нужными автоматике.

Ещё входят примеры персонажей и монстров, придуманные для этого проекта (не из книг), и встроенное руководство по заполнению.

## Чего нет и как это добавить

Оружия, брони, предметов, заклинаний, талантов и монстров в комплекте нет. Мастер вносит их сам, по своим книгам:

- **Конструктор предметов** — формы для оружия, брони, аксессуаров, снаряжения, заклинаний, талантов, приворотов алхимика и мелодий барда. Игроки могут пользоваться им для своих персонажей.
- **Генератор монстров** — ввод чисел вручную или вставка текста блока монстра, набранного или скопированного самим мастером; есть монстры из нескольких секций.
- **Импорт ytsheet** — листы персонажей и монстров, созданные игроками на ytsheet, загружаются как JSON.

## Установка

Foundry VTT → Игровые системы → Установить систему → вставить ссылку на манифест:

```
https://github.com/IIP0CTOy/sw25-ru/releases/latest/download/system.json
```

Для русского интерфейса самой Foundry нужен модуль перевода ядра `ru-ru`.

## Поддержка

Система бесплатная. Если хотите поддержать автора — [Boosty](https://boosty.to/iipoctoy_foundry_vvt). Спасибо!
